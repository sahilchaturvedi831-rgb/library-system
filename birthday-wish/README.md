# Happy Birthday Wisher

A festive website to generate personalized birthday wishes with emojis and animations.

## How to Run on Any Device

### Method 1: Direct File Opening (Works on any device with a web browser)

1. **Transfer the files**: Copy the entire `birthday-wish` folder to your device using:
   - USB drive
   - Cloud storage (Google Drive, Dropbox, etc.)
   - Email attachment
   - File sharing apps

2. **Open the website**:
   - Locate the `birthday-wish` folder on your device
   - Open the `index.html` file with any web browser (Chrome, Firefox, Safari, Edge, etc.)
   - The website will load and be fully functional

### Method 2: Local Web Server (For better performance and features)

#### On Windows:
1. Open Command Prompt in the `birthday-wish` folder
2. Run: `python -m http.server 8000`
3. Open `http://localhost:8000` in your browser

#### On macOS/Linux:
1. Open Terminal in the `birthday-wish` folder
2. Run: `python3 -m http.server 8000`
3. Open `http://localhost:8000` in your browser

### Method 3: Online Hosting (Accessible from any device with internet)

1. **GitHub Pages** (Free):
   - Upload the `birthday-wish` folder to a GitHub repository
   - Go to Settings → Pages → Source: main branch
   - Your site will be available at `https://yourusername.github.io/repository-name`

2. **Netlify** (Free):
   - Drag and drop the `birthday-wish` folder to netlify.com
   - Get a free URL like `https://amazing-birthday.netlify.app`

3. **Vercel** (Free):
   - Upload to vercel.com
   - Get instant hosting

### Requirements

- **Internet connection**: Required for loading external images from Unsplash
- **Modern web browser**: Chrome, Firefox, Safari, Edge (latest versions recommended)
- **No installation needed**: Works directly in any web browser

### Features

- Enter a name and generate random birthday wishes
- Festive animations and floating images
- Responsive design for mobile and desktop
- Emoji-rich messages

Enjoy wishing happy birthdays! 🎉
