# Java FAQ Chatbot (Swing)

A standalone Java desktop chatbot using simple NLP (token normalization + overlap scoring) and a FAQ dataset.

## Prerequisites
- Java 8+ (JDK)

## Run (Windows)
- Double-click: `build_and_run.bat`
- Or compile/run from CMD:
  ```bat
  javac -d out src/*.java
  java -cp out ChatbotGUI
  ```

## FAQ dataset
- Edit `faq.json` to add/update questions and answers.
